This skill is a convenience entry point that bundles the core SvelteKit skills. When working on a SvelteKit project, apply all of the following skill files:

- `sveltekit-project-structure` — routing conventions, file layout, TypeScript setup, adapters, styling
- `sveltekit-state` — Svelte 5 runes, load functions, shared state, error handling
- `sveltekit-forms` — form actions, validation, progressive enhancement
- `sveltekit-testing` — Vitest, Testing Library, Playwright, TDD workflow

Read each of those skill files now and apply their standards for the entire session.
